# 选题评估

使用 `assets/topic-backlog.template.md` 记录候选题；评分规则见 `references/scoring-rubric.md`。

## 工作流

1. 写清选题的一句话判断、目标读者和触发它的真实场景。
2. 对好奇心、信息增量、情绪共鸣、作者资格、时效风险各打 1–5 分。
3. 找出文章必须回答的一个问题和至少一个可验证的证据来源。
4. 给出“现在写 / 补材料后写 / 暂缓”结论，并说明唯一最该补的材料。

不要把热度当作价值；没有作者独有观察或证据的题目，优先暂缓。
