# 标题优化

先读文章主张，使用 `assets/title-matrix.template.csv` 生成候选，评分标准见 `references/title-rubric.md`。

## 工作流

1. 锁定读者、人群困惑、不可替换的技术词和文章真正能兑现的价值。
2. 沿“精准人群、信息增量、反常识、具体场景”四个方向各写 3 个标题。
3. 按准确性、好奇心、可读性、差异化评分；准确性低的标题直接淘汰。
4. 推荐 3 个，并说明适用场景和可能误读。

禁止承诺正文无法证明的收益；标题保留必要技术词，但用普通人能理解的动词和场景降低门槛。
