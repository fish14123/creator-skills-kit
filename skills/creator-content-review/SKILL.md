# 数据复盘

复制 `assets/content-review.template.csv` 记录每篇内容；指标定义见 `references/metrics-guide.md`。

## 工作流

1. 记录标题、发布时间、主题、分发渠道和可获得的阅读、分享、收藏、涨粉、取关、完读等数据。
2. 区分事实数据、读者反馈和作者主观感受，避免只凭一篇内容下结论。
3. 与同主题或同渠道的历史内容比较，提出一个可验证假设。
4. 为下一篇写下一个具体实验：改标题、换开头、调整选题、改变发布时间，且只优先改变一项。

不要用单次波动给内容贴“成功/失败”标签；长期积累可比较的记录比追逐单篇爆款更重要。
