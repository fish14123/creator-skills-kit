# 长文结构

先填 `assets/article-brief.template.md`，再按 `references/structure-patterns.md` 选择结构。

## 工作流

1. 用一句话锁定文章主张：读者读完后应改变什么认识。
2. 区分“事实、例子、判断、待核材料”；没有证据的判断不扩写成结论。
3. 选择最小有效结构：问题—判断—证据—方法—回环，或故事—转折—拆解—行动。
4. 给每一节写一句功能说明，确保删掉任一节都会损失信息，而不是只损失篇幅。

输出文章地图、三级大纲、每节证据缺口和开头/结尾各 2 个方向；不要直接把素材拼成长段落。
