# 两种常用结构

## 判断型

问题场景 → 核心判断 → 证据/案例 → 方法或边界 → 回到读者行动。

适合材料足以支持一个明确判断。核心结论尚无证据时，改成待回答的问题，并将相关章节标为暂定。

## 故事型

具体故事 → 意外或转折 → 拆解原因 → 可迁移的方法 → 克制的结尾。

适合已有可追溯的事件、人物和过程。缺真实事件材料时，使用判断型；不为制造转折虚构经历。

两种结构可组合；只有用户要求且材料支持时才增加其他叙事层次。

## 材料标记

| 标记 | 含义 | 大纲中的用法 |
| --- | --- | --- |
| F | 可客观核对的事实主张 | `[F:S1]`，同时查看材料表的主张判定 |
| E | 具体案例或观察 | `[E:S2]`，保留人物、时间、条件和来源范围 |
| J | 作者判断或推论 | `[J:S1,S2]`，说明依据及仍可能存在的其他解释 |
| U | 待核主张或缺失材料 | `[U:缺口1]`，说明需要什么来源或观察才能使用 |

材料表把“来源核对动作”和“主张判定”分开：前者仅为“未读取 / 已读取”，表示是否读到相关内容；后者使用以下七态。

| 主张判定 | 含义 |
| --- | --- |
| 待核验 | 尚未完成证据核对，不能判断真伪 |
| 已证实 | 直接且可靠的证据支持原主张及其适用范围，且无未解决的关键反证 |
| 有条件成立 | 仅在写明的版本、时间、人群或其他条件下成立 |
| 无法证实 | 已查阅现有材料，仍无足够证据支持或否定 |
| 已证伪 | 可靠、适用且直接的证据足以否定原主张 |
| 与来源冲突 | 可靠证据互相矛盾且暂不能解释 |
| 已过时 | 过去成立，但已不适用于当前时间或版本 |

纯主观建议另填“不适用（主观判断）”；其中夹带的事实仍须拆出核查。已读取不自动升级主张判定，“无法证实”也不等于“已证伪”。
只有已证实或写清条件后有条件成立的事实可作为确定支撑；待核验、无法证实用 U 标记缺口。已证伪、与来源冲突、已过时主张须纠正、收窄或删除，不作大纲确定依据。
同一段可同时有 F 与 J，但要分清证据和推论；案例可说明可能性，不能单独证明普遍效果或因果关系。

## 每节检查

- 功能：这一节回答哪个子问题？
- 主张：它与全文主张是什么关系？
- 依据：哪些材料编号直接支持它，适用条件是否一致？
- 缺口：未补齐会影响哪项结论，能否删除、收窄或改成问题？

大纲足以让作者知道每节写什么即可，不要求固定节数或每节都达到三级。
