# 来源与判定规则

## 取证

1. 官方原始公告、产品文档、原始数据、论文。
2. 可追溯的专业媒体或研究机构。
3. 当事人公开发言或可靠采访。
4. 其他报道仅作线索，不能单独支撑关键结论。

来源是否直接支撑主张，比来源数量更重要。涉及产品功能、价格、政策和数据，优先核对对应版本的一手来源；官方营销表述不等于独立性能证明。采访能证明“某人如此说过”，不自动证明其内容真实。

对关键主张主动找反证：阅读限制条件、变更日志、更正或撤回，并检索相反说法。每个“主张ID × 来源”一行，来源作用填“支持 / 反对 / 背景”；同一来源兼有支持与限制时可拆行。记录章节、页码、段落或时间戳等定位，并摘录短句或标明“转述”。发布日期、访问日期、核验日期分别记录为 `YYYY-MM-DD`；未知发布日期留空，不拿访问日期代替。

不同来源冲突时，先比较定义、数据期间、版本、地区和统计口径；不能解释就交付冲突及待补材料。新公告可能使旧资料失效，旧资料仍可支持带日期和版本的历史表述。

## 状态与动作

| 状态 | 使用条件 | 动作 |
|---|---|---|
| 待核验 | 尚未实际核验，或缺少访问条件 | 列出所需来源；不当作可发布事实 |
| 已证实 | 实际读取的可靠证据直接支持，且无未解决的关键反证 | 按证据的日期、版本与范围表述 |
| 有条件成立 | 仅在明确版本、地区、前提或定义下成立 | 将条件写进正文 |
| 无法证实 | 已查找但证据不足，既不能确认也不能否定 | 删除或标注未核实，列出缺口 |
| 已证伪 | 可靠、适用且直接的证据足以否定原主张 | 纠正或删除，写明反证 |
| 与来源冲突 | 可靠证据互相矛盾且暂不能解释 | 展示双方依据，暂停确定性结论 |
| 已过时 | 曾在已知范围内成立，已有更新使其不再适用于当前表述 | 更新正文，或明确改写成历史表述 |

主观偏好不判“已证实”；标明它属于作者判断，并单独检查其事实前提。用户给出的截图、资料只能支持其实际包含的内容；离线材料不能证明价格、规则等截至今天仍然有效。
