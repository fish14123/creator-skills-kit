# 资料研究与事实核查

复制 `assets/claim-ledger.template.csv` 建立主张台账；来源分级见 `references/source-policy.md`。

## 工作流

1. 把文章拆成可核验主张：事实、数字、功能、规则、引语、案例。
2. 优先找一手来源：官方文档、原始公告、论文、原始数据；记录链接、发布日期和访问日期。
3. 每条主张标注“已证实 / 有条件成立 / 无法证实 / 已过时”，以及可安全使用的表述。
4. 发布前检查绝对化语言、过期版本、二手转述和没有来源的数字。

找不到可靠依据时，删除、降格为个人观察，或明确写出不确定性；不得用编造引用补空缺。
