# 多平台分发

先用 `assets/distribution-plan.template.md` 记录原文边界；平台改写规则见 `references/platform-adaptation.md`。

## 工作流

1. 提取不可改变的核心判断、事实链接、作者经历与禁止夸大的部分。
2. 为每个平台重写开头、结构密度、标题和互动方式；不要只替换同义词。
3. 标出需要作者补充或重核的内容，特别是跨文化替换、时间敏感数据和平台规则。
4. 交付各平台草稿、标题/摘要/标签、配图方向和发布前检查清单。

此 Skill 只生成草稿，绝不代表作者自动发布，也不编造案例、数据或个人经验。
