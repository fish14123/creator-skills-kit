# 平台适配原则

以下是可调整的写作起点，不代表平台当前算法、流量偏好或发布规定。用户给定的读者、体裁和要求优先；未列出的平台也按同一方法适配。

| 场景 | 可选的改写方向 |
|---|---|
| 知乎问答 | 对齐具体问题，先给结论，再展开证据；只使用原文真实经历 |
| 头条等大众图文 | 补足读者理解所需的背景，具体化已有场景，解释术语 |
| 百家等方法文章 | 按问题、步骤和适用条件组织，保留事实来源 |
| 小红书等短图文 | 在用户要求的篇幅内拆成可独立理解的要点，保留必要条件与来源入口 |
| 英文或其他语言长文 | 解释文化背景和专有名词，保留产品名、数字与限制；不虚构本地替代案例 |
| 用户自定平台 | 按目标读者、载体和篇幅要求设计结构，不默认套用其他平台格式 |

“点个在看”等渠道表达可按目标平台改写或删去；用户未要求互动时不强加关注、转发或购买引导。原文标题依赖公众号上下文时，补足主题，不为吸引点击扩大结论。

原文的证据编号、链接、时间、版本和条件应随相关主张一起迁移；正文不便放链接时，在来源清单保留主张对应关系。不得用译文或改写抹掉限定词，不能把“可能改善”改成“保证有效”。

平台字数限制、链接政策和发布规则等时效信息，只有核对当前官方材料后才标为“已核验”，并记录链接、发布日期（若可得）和核验日期。仅有旧材料时注明旧版本；无法核验则交付待确认项，不宣称“符合最新规则”。
